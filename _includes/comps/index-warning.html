Directory Warning

{{ _title }}

The directory {{ _path }} does not contain an index.md or index.html file. Without one, Jekyll may expose a raw file listing or return a 404.

Quick Fix — create an index page

Create {{ _path | append: "index.md" }} with the following minimal front-matter:

---
title: "Your Page Title"
layout: default
description: "A short description of this section."
---

QOL Tips & Best Practices
  • Collections: Every collection folder (e.g. _tutorials/) should have a corresponding output index page at its permalink root (e.g. /tutorials/index.md).
  • Disable sidebar per-page: Add sidebar: false to front-matter for landing/index pages that don't need navigation.
  • Layout variants: Use layout: splash for marketing-style landing pages with no sidebar or TOC chrome.
  • Suppress this warning: Once an index file exists, this component auto-resolves. You can also pass hide_tips: true to suppress the tips panel only.
  • Permalink tip: Set permalink: /your-path/ in front-matter to ensure the URL resolves cleanly regardless of Jekyll's default permalink strategy.
