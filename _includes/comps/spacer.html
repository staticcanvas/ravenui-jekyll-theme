{%- comment -%} Component__: Spacer Purpose____: Adds configurable vertical whitespace between layout elements. Useful when constructing pages with blank or splash layouts where normal markdown paragraph spacing is insufficient. Usage______: Basic (named size): {% include comps/spacer.html size="md" %} Custom height: {% include comps/spacer.html height="4rem" %} With a visual divider line: {% include comps/spacer.html size="lg" divider=true %} With a gradient divider: {% include comps/spacer.html size="xl" divider=true divider_style="gradient" %} Parameters_: size (optional) — Named size token. Takes precedence over `size`. divider (optional) — Set to true to render a subtle horizontal rule at the vertical midpoint of the spacer. divider_style (optional) — Style of the divider line.
